# Retail Sales Data Analysis

## Project Overview
This project focuses on cleaning, analyzing, and visualizing a retail sales dataset to uncover meaningful business insights.

The workflow includes:
- Data cleaning and preprocessing
- Handling missing values and duplicates
- Standardizing categorical data
- Outlier detection and treatment
- Exploratory Data Analysis (EDA)
- Revenue and sales trend analysis
- Business insight generation through visualizations

The project was implemented using Python in Jupyter Notebook.

---

## Dataset Features

The dataset contains transactional retail data including:

- Transaction Date
- Customer ID
- Region
- Product Category
- Units Sold
- Unit Price
- Revenue
- High Value Transactions

---

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

---

## Project Workflow

### 1. Data Cleaning
- Removed duplicates
- Handled missing values
- Fixed inconsistent categorical labels
- Converted data types
- Standardized text formatting

### 2. Feature Engineering
- Calculated expected revenue
- Created cleaned revenue values
- Processed transaction dates
- Converted high-value indicators to boolean format

### 3. Outlier Handling
Applied the IQR method to cap extreme values in:
- Revenue
- Units Sold

### 4. Exploratory Data Analysis (EDA)
Performed analysis on:
- Revenue distribution
- Regional performance
- Product category performance
- Sales trends over time
- High-value transactions

### 5. Data Visualization
Generated visualizations to better understand:
- Revenue distribution
- Product category comparisons
- Regional sales performance
- Revenue trends over time

---

## Key Insights

Some important findings from the analysis include:

- Revenue distribution is highly right-skewed
- Certain product categories generate significantly higher revenue
- Regional sales performance varies considerably
- A small number of transactions contribute heavily to total revenue
- Outlier treatment improved data consistency and analysis quality
